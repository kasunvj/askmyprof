ASKMYPROF - PROJECT OVERVIEW
========================================

PROJECT DESCRIPTION
===================
AskMyProf is a modern web application built with the MERN stack (MongoDB, Express, React, Node.js)
that streamlines the process of requesting letters of recommendation between students and professors.

KEY FEATURES
============
✓ User Authentication
  - Secure signup and login system
  - Role-based access control (Student/Teacher)
  - JWT token-based authentication
  - Password encryption with bcrypt

✓ Student Features
  - Clean landing page with visual elements
  - Request letters from registered professors
  - Select professor from dropdown list
  - Add personalized messages to requests
  - Track request status in dashboard
  - View all submitted requests

✓ Teacher Features
  - Custom display name for student visibility
  - View all incoming requests
  - See student details and messages
  - Approve or reject requests
  - Dashboard showing all request history

✓ User Interface
  - Modern, clean design
  - Theme colors: White, Red (#DC143C), Yellow (#FFD700)
  - Responsive layout (works on all devices)
  - Smooth animations and transitions
  - Intuitive navigation
  - Visual representation of student/supervisor

TECHNICAL ARCHITECTURE
======================

Backend (Node.js + Express)
---------------------------
- RESTful API architecture
- MongoDB database with Mongoose ODM
- JWT for authentication and authorization
- Express middleware for request validation
- Secure password hashing with bcryptjs
- CORS enabled for cross-origin requests
- Input validation and sanitization

Frontend (React)
----------------
- React 18 with functional components and hooks
- React Router v6 for navigation
- Context API for global state management
- Axios for HTTP requests
- Protected routes with authentication
- Responsive CSS with custom styling
- Component-based architecture

Database Schema
---------------
Users Collection:
  - username (unique)
  - email (unique)
  - password (hashed)
  - role (student/teacher)
  - displayName
  - createdAt

LetterRequests Collection:
  - student (ref to User)
  - teacher (ref to User)
  - status (pending/approved/rejected)
  - message
  - createdAt
  - updatedAt

USER WORKFLOWS
==============

New User Registration:
1. Navigate to application
2. Click "Sign Up"
3. Select role (Student/Teacher)
4. Fill registration form
5. Submit and auto-login
6. Redirect to dashboard

Student Request Flow:
1. Login as student
2. Click "Request a Letter"
3. Select professor from dropdown
4. Add optional message
5. Submit request
6. View in dashboard (status: pending)
7. Receive status updates (approved/rejected)

Teacher Review Flow:
1. Login as teacher
2. View dashboard with incoming requests
3. Review student information
4. Read personal message
5. Click "Approve" or "Reject"
6. Status updates instantly
7. Student sees updated status

API ENDPOINTS SUMMARY
=====================

Authentication:
  POST   /api/auth/signup          Create account
  POST   /api/auth/login           Login user

Letter Requests:
  GET    /api/letter-requests/teachers       List all teachers
  POST   /api/letter-requests                Create request (student)
  GET    /api/letter-requests/my-requests    Get user's requests
  PATCH  /api/letter-requests/:id/status     Update status (teacher)

Health Check:
  GET    /api/health                         Server status
