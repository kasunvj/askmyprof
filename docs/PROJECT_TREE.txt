========================================
DATA FLOW
========================================

User Registration:
  Signup.js → POST /api/auth/signup → User.js → MongoDB
      ↓
  Receives JWT token
      ↓
  AuthContext stores token + user
      ↓
  Redirects to Dashboard

User Login:
  Login.js → POST /api/auth/login → User.js → MongoDB
      ↓
  Receives JWT token
      ↓
  AuthContext stores token + user
      ↓
  Redirects to Dashboard

Letter Request (Student):
  RequestLetter.js → GET /api/letter-requests/teachers
      ↓
  Displays teachers in dropdown
      ↓
  User selects teacher and submits
      ↓
  POST /api/letter-requests → LetterRequest.js → MongoDB
      ↓
  Redirects to Dashboard
      ↓
  Dashboard shows request (status: pending)

Request Review (Teacher):
  Dashboard.js → GET /api/letter-requests/my-requests
      ↓
  Displays incoming requests
      ↓
  Teacher clicks Approve/Reject
      ↓
  PATCH /api/letter-requests/:id/status → LetterRequest.js
      ↓
  Status updated in MongoDB
      ↓
  Dashboard refreshes with new status

========================================
AUTHENTICATION FLOW
========================================

Protected Routes:
  App.js
    └── ProtectedRoute component
        └── Checks AuthContext.isAuthenticated
            ├── True  → Render page
            └── False → Redirect to /login

Token Storage:
  AuthContext
    ├── Login/Signup → Store token in localStorage
    ├── Logout → Remove token from localStorage
    └── Page load → Restore token from localStorage

API Requests:
  AuthContext.getAuthHeader()
    └── Returns: { Authorization: "Bearer <token>" }
        └── Sent with all protected API calls
            └── Backend: auth.js middleware verifies token
